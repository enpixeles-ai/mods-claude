# Mods de Claude Code · EnPíxeles

Mods gratis para Claude Code, en español.

Un **mod** es un añadido que se mete dentro de Claude Code y le pone cosas encima: avisos, paneles, frenos de seguridad. Como en los videojuegos.

## 🔑 Guardia de Llaves

Tapa tus contraseñas y llaves de API **antes** de que Claude las vea.

Claude recibe esto:

```
GEMINI_API_KEY=AIzaSyD4…TAPADO
```

[Leer el manual completo](guardia-llaves/README.md)

## Instalar

Necesitas Claude Code 2.1.287 o más nuevo (`claude --version`).

```bash
claude plugin marketplace add enpixeles-ai/mods-claude
```

```bash
claude plugin install guardia-llaves@enpixeles
```
